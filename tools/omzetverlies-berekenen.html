● Gratis tool · Wat kost een trage site je?

Hoeveel klanten kost een trage website je?Reken uit wat een paar seconden wachten je per maand kost.

Elke seconde dat je site langer laadt, haken er bezoekers af. Die zien je aanbod nooit, en vragen dus ook niets aan. Met deze rekenhulp zie je wat dat ongeveer kost, uitgedrukt in klanten en euro's.

Wat je ziet

  • ✓ Hoeveel extra klanten je per maand zou kunnen hebben
  • ✓ Wat dat oplevert per maand en per jaar
  • ✓ Hoeveel sneller je site zou moeten

Veelgestelde vragen

Hoe betrouwbaar is deze berekening?

Het is een schatting met een veelgebruikte vuistregel: elke seconde extra laadtijd kost ongeveer 7% van je aanvragen. De echte uitkomst verschilt per website.

Hoe weet ik hoe snel mijn site is?

Doe de gratis snelheidstest. Daar zie je ook wat je site vertraagt.

Hoe maak ik mijn site sneller?

Vaak met lichtere foto's, minder plugins en betere hosting. Sitehulpje kan dit voor je oppakken.
