● Gratis tool · Veiligheidscheck

Is je website veilig?Gratis check op slotje, instellingen en zwakke plekken.

Een gehackte website kost tijd, geld en vertrouwen. Vaak zit het probleem in kleine dingen: een ontbrekende instelling, een server die verraadt welke software hij draait, of onderdelen die nog onveilig worden ingeladen. Deze check laat zien waar je staat.

Wat we controleren

  • ✓ Of je site een slotje heeft (https) en bezoekers daar altijd naartoe gaan
  • ✓ Of browsers onthouden dat je site veilig is
  • ✓ Of je site in een nep-pagina geladen kan worden
  • ✓ Of je server softwareversies verraadt
  • ✓ Of alles veilig wordt ingeladen

Veelgestelde vragen

Mijn site heeft een slotje, is hij dan veilig?

Het slotje is de basis, maar niet alles. Ook de instellingen van je server en up-to-date software zijn belangrijk.

Kunnen hackers deze check misbruiken?

Nee. We bekijken alleen wat elke bezoeker ook kan zien. We proberen niets te kraken.

Wat als er rode punten zijn?

Laat ze oplossen door je webbouwer of door Sitehulpje. De meeste punten zijn kleine instellingen die in één keer goed staan.
